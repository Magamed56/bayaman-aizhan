## Как поменять данные

Всё — в **`config.js`**: имена, `hosts` (той ээлери), дата и время,
ресторан (`venueName`, `routeUrl` — ссылка 2GIS, `coords` — для карты), тексты и заметки
(`notes`, иконки `clock | flower | camera | heart | gift | music | dress`), русские тексты в `ru`.

Если меняются имена или дата — пересоздайте `assets/og.jpg` (скриншот `og.html` 1080×1080)
и `assets/toy.ics` (календарь для iPhone).

Музыка — `assets/music.mp3` (сейчас «Свадебная» — Мот, как у прошлых пар). Чтобы поставить другую
песню, замените файл, имя оставьте тем же.

## Куда приходят ответы гостей

Проверяется по порядку:

1. **Telegram** — `telegram: { token, chatId }`: бот-администратор в канале/группе пары,
   id группы — из `https://api.telegram.org/bot<TOKEN>/getUpdates`.
2. **Google Таблица** (ответы + пожелания на сайте + счётчик просмотров) — создайте таблицу →
   Расширения → Apps Script → вставьте `google-apps-script.js` → сохраните → выполните `setupSheet`
   (разрешите доступ: «Дополнительно» → «Перейти к проекту») → Развернуть → Новое развёртывание →
   Веб-приложение, «Выполнять от имени: Я», «Доступ: Все» → URL (…/exec) вставьте в `googleScriptUrl`.
   В листе «Жооптор»: время, имя, ответ, число гостей, пожелание и галочка «Сайтта»;
   справа итоги. Проверка версии: `…/exec?action=version`. Пожелания с галочкой «Сайтта»
   показываются на сайте в разделе «Каалоолор».
3. **WhatsApp** — `whatsapp: "996…"`: гость сам отправляет готовое сообщение.

## Публикация

GitHub Pages раздаёт ветку `gh-pages`. Workflow `.github/workflows/deploy.yml` при каждом пуше
в `main` копирует её в `gh-pages` (и проставляет версию файлов, чтобы телефоны не показывали старое).
Один раз включите: Settings → Pages → Build and deployment → Deploy from a branch → `gh-pages` / `(root)`.

Локально: `python3 -m http.server 8080` → http://localhost:8080
